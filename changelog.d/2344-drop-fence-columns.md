### Upgrade notes

- **This release drops two columns from `sandboxes`: `reset_requested_at` and `teardown_requested_at`** (#2344). Every replica must already run **v0.20.0 or later**, which stopped reading them (#2423), before this migration runs. A replica on an older release reads both columns and fails every sandbox query once they are gone. Upgrade from an earlier release to v0.20.0 first, and let it finish rolling. This release's migrations include v0.20.1's backfill, which stamps any deletion or reset that a v0.19.0 instance recorded only in these columns. That backfill runs before the drop, so no pending deletion is lost, and it needs no operator action. A rollback of the migration adds the columns back empty.
